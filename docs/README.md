# UeePayFrontend 文档索引

以项目 `AGENTS.md` 为工作入口，再按下表读取当前任务直接相关的规范和章节。上级 `../AGENTS.md` 的共同安全底线持续适用；普通单项目任务不默认全文读取上级规则或全部专项文档。

## 按需读取方法

1. 根据任务关键词在“文档导航”中选择候选文档；不得为了解项目而一次性读取全部文档。
2. 打开候选文档前，先检索其标题和任务关键词，确定需要读取的章节范围。
3. 只读取命中章节及必要的上下文；文档中的链接按实际依赖继续定位，不递归展开全部引用。
4. 跨领域任务分别读取各规范的相关章节，不因同时命中多份规范而阅读全文。
5. 只有局部章节无法独立解释规则、出现规则冲突、涉及安全底线，或任务本身要求审查整份文档时，才扩大读取范围，并记录原因。

## 规则与事实

- 规则冲突统一按[文档治理与冲突处理规范](./文档治理与冲突处理规范.md)裁决；安全、资金、权限、KYC/KYB、2FA、风控和敏感信息规则累积生效，无法同时满足时停止变更并请求确认。
- 用户明确要求决定任务范围和授权，不自动扩大修改、构建或发布范围。
- 子项目和专项规范负责具体领域且不得弱化安全底线；文档与代码、配置或命令不一致时，代码决定当前事实，规范决定目标，不为匹配文档擅自改变业务行为。

## 维护要求

- 命令、依赖、构建、测试或发布流程变化时，同步更新 `README.md` 及对应专项规范。
- 路由、Store、共享组件、多语言、主题或其他领域入口变化时，只更新对应权威规范；其他文档保留触发条件和链接。
- 规则优先级、授权边界或临时例外变化时更新治理规范；新增文档时加入本索引并说明边界，示例只使用当前项目事实。
- AI 入口统一使用项目 `AGENTS.md` 与本索引，不在专项文档复制长提示词；修改 Markdown 文档后运行 `yarn docs:check`。
