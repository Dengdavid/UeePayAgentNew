# UeePayFrontend 项目定位

本文档用于统一 UeePayFrontend 的产品定位、核心能力、目标用户和品牌表达边界。

本文档不规定页面结构或视觉实现。涉及 UI、组件、响应式、可访问性、公开文案、安全或多语言时，仍以[设计规范](./设计规范.md)、[安全与数据处理规范](./安全与数据处理规范.md)和[多语言规范](./多语言规范.md)为准。

## 1. 产品定位

UeePayFrontend 是 UeePay 面向个人用户、企业用户、潜在客户和开放平台客户的用户端，包括官网与登录后的用户中心。

UeePay 是一个面向全球数字业务的跨境支付与虚拟卡管理平台，核心能力包括：

- 虚拟卡申请、批量发卡与额度管理。
- 广告投放、AI / SaaS、云服务和全球订阅等场景支付。
- 多币种充值、结算、提现与财务流水管理。
- KYC / KYB、2FA、安全验证与风险控制。
- API 接入、代理运营和企业品牌合作方案。

推荐的一句话定位：

> 为全球数字业务提供合规、可管理、可追踪的虚拟卡与跨境支付基础设施。

## 2. 目标用户

主要用户：

- 跨境电商、广告投放和媒体采购团队。
- AI、SaaS、云服务等全球订阅付费团队。
- 需要批量虚拟卡、项目预算和对账管理的企业。
- 有国际采购、海外服务订阅需求的中小企业。

次级用户：

- 需要 API 发卡能力的技术平台。
- 支付服务商、渠道商和代理合作伙伴。
- 需要独立品牌运营方案的企业客户。
- 有合规跨境支付和虚拟卡需求的个人用户。

产品叙事以 B2B 企业支付平台为主，同时保证个人用户能够清晰理解和使用与其账户相关的服务。

## 3. 产品边界

- 本项目是用户端，不是总平台控制端或代理端。
- 服务端是权限、数据归属、认证、卡状态、资金结果、风控和地区限制的最终边界。
- 前端负责清晰、安全地展示服务端结果并完成用户交互，不在本地决定资金或合规结果。
- 官网负责准确介绍产品能力；用户中心负责账户、认证、卡片、资金、交易和开放平台等业务操作。
- 支持范围、费率、到账时间、审核结果和合作关系必须基于可验证事实，不作不确定承诺。

## 4. 品牌表达

品牌表达以“可靠、透明、易管理”为核心，呈现专业、可信、国际化的企业金融科技平台形象。

不应将 UeePay 表现为：

- 消费级礼品卡网站。
- 加密货币交易平台。
- 强调快速收益的代理平台。
- 承诺“零风险”“全球通用”“百分百成功”或不确定金融结果的平台。

公开页面、帮助中心、协议、通知和认证文案应保持正式、准确、合规，并清楚区分平台能力、合作方能力和受地区或机构限制的服务。
