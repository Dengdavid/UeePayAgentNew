# UeePayAgent 项目定位

本文档用于统一 UeePayAgent 的产品定位、核心能力、目标用户和品牌表达边界。

本文档不规定页面结构或视觉实现。涉及 UI、组件、响应式、可访问性、公开文案、安全或多语言时，仍以[设计规范](./设计规范.md)、[安全与数据处理规范](./安全与数据处理规范.md)和[多语言规范](./多语言规范.md)为准。

## 1. 产品定位

UeePayAgent 是优易付代理商端白标站点前端。应用按访问域名获取站点配置，并通过统一的 `/agent` 请求入口连接代理商端服务。

当前实现包含两个相互关联的使用区域：

- 代理站点用户中心：账户、卡片、认证、资金、Express、消息和安全设置等页面。
- 授权管理员后台：营销、用户、账单、定价、菜单、公告和站点配置等运营页面。

具体页面、服务和操作是否可用，由服务端返回的用户身份、站点配置、地区限制和风控结果决定，不因前端存在入口而默认开放。

推荐的一句话定位：

> 面向代理商白标站点的用户服务与授权运营前端。

## 2. 目标用户

主要用户：

- 在代理站点完成注册或登录，并使用账户相关服务的个人或企业用户。
- 经服务端认定、可进入站点运营后台的授权管理员。

用户身份、数据归属和管理员权限均以服务端结果为准。前端不得通过路由参数、本地状态或自行传入用户标识扩大访问范围。

## 3. 产品边界

- 本项目不是 `UeePayFrontend` 用户端，也不是服务端或优易付总平台控制端。
- 服务端是租户归属、权限、认证、卡状态、资金结果、风控和地区限制的最终边界。
- 前端负责按站点配置展示品牌与业务入口，并安全地呈现服务端结果，不在本地决定资金、权限或合规结果。
- 页面和接口代码只证明前端存在实现，不能据此承诺具体卡种、币种、地区、费率、到账时间、审核结果或生产环境能力。
- 未接入当前路由或未得到服务端授权的页面，不应描述为已正式开放的产品能力。

## 4. 品牌表达

运行时品牌名称、Logo、登录背景、客服入口等内容来自站点配置。白标站点应使用其实际配置进行展示，不应把所有代理站点固定描述为 UeePay 官方网站。

品牌表达应保持专业、可信、清晰，并避免：

- 混淆代理站点、优易付用户端和总平台后台的职责。
- 承诺“零风险”“全球通用”“百分百成功”或其他不确定金融结果。
- 把服务端尚未确认的支持范围、合作关系或合规资质写成既定事实。

公开页面、协议、通知和认证文案应保持正式、准确、合规，并清楚区分站点能力、平台能力、合作方能力以及受地区或机构限制的服务。
